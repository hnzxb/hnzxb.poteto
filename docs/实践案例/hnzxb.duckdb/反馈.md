### 形同虚设 / 盲区（核心反馈）

1. **新功能零覆盖**：cli.js（citty 双命令）、src/documents.js、src/projects.js、src/summarize.js 均为 untracked 且无任何测试行——`check` 全绿是"旧表面绿"，验证层没有随功能扩张。这正是 poteto「feature map 漂移」的实例：项目缺 `docs/功能地图.md`，新功能就没有"必须登记验证命令"的锚点。
2. **SQL 拼接未复发（澄清）**：初判 `INSERT INTO ... VALUES ${values}` 为注入复发，细读后 VALUES 是 `?` 占位 + params 参数化，表名为字面量——不构成注入。教训：分层核对必须读到参数化细节再判定，grep 命中≠违规。
3. **仓库卫生**：`.impeccable/hook.cache.json`（工具缓存）与 `data/`（运行产物）被卷入 git 视野，应进 .gitignore；`archive/`、`docs/工作记录/` 未提交；master ahead 4 未推送。
