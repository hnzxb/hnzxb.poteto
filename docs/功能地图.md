# 功能地图

> poteto 工具箱自身的验证依据。改 bin/poteto.js 后必须 `bun test:self` 全绿再推送——2026-11-23 的 `\n` 转义事故（生成的 check.js 语法错误出门）就是没跑这条门禁的代价，已记入纠错台账。

| 功能 | 到达路径 | 验证命令 | 证据形态 |
|---|---|---|---|
| init 安装 skills/文档/自检脚本 | `bin/poteto.js init` | `node tests/poteto/toolbox.test.js` | 4 项 ✅ + 全部通过，exit=0 |
| 生成脚本语法正确 | init → `tests/poteto/check.js` | 同上（第 2 项） | node 可解析并输出「完整」 |
| 自检失败路径 | check.js 缺文件场景 | 同上（第 3 项） | exit=1 |
| list/read/skills | `bin/poteto.js` | 同上（第 4 项） | 输出包含对应内容 |
